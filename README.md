# 人物形象冰箱贴 · Person Fridge Magnet

根据真实人物照片，生成竖版 3:4 极简旅行摄影海报。将人物提取为简约冰箱贴式图标，配合手写姓名形成连续刀模结构，整体呈现小红书城市打卡 / 冰箱贴 / 极简拼贴风格。

## 效果特点

- **竖版 3:4** 极简纯白背景
- 人物提取为**简约冰箱贴式图标**，保留核心轮廓与标志性特征
- 手写姓名与人物轮廓融合，形成**连续刀模结构**
- 主体外圈为**一圈连续的细白实线描边**（默认无灰色虚线；仅在厂家开模时额外加浅灰裁切辅助线）
- 服装颜色提亮鲜艳，形成色彩记忆点
- 整体清爽、干净、明亮，有城市漫游感和旅行打卡氛围

## 输入要求

| 输入 | 说明 |
|---|---|
| 真实照片 | 一张包含清晰人物的真实照片 |
| 姓名 | 要写入海报的姓名（手写体） |

## 安装

本技能是**纯提示词型技能**（仅 `SKILL.md`，无脚本、无联网、无文件操作），可跨平台使用。

```bash
# 豆包办公 / Doubao Work
# 将整个 person-fridge-magnet 文件夹放入用户技能目录
# 路径通常为：workspace/.user_skills/person-fridge-magnet/

# WorkBuddy
# 将整个 person-fridge-magnet 文件夹放入用户级技能目录
# 路径：~/.workbuddy/skills/person-fridge-magnet/
# Windows 实际路径示例：C:\Users\<用户名>\.workbuddy\skills\person-fridge-magnet\
```

确保目录结构为：

```
person-fridge-magnet/
└── SKILL.md
```

安装后**重启 / 刷新对话**以加载新技能。

## 出图参数（WorkBuddy 已固化）

在 WorkBuddy 中调用内置 ImageGen 图像生成工具，参数已实测验证，直接套用：

| 参数 | 固定值 | 说明 |
|---|---|---|
| 调用方式 | 图生图 | 必须传入用户原图作为参考图 |
| `input_fidelity` | `high` | 高保真，保证人物辨识度 |
| `size` | `1024x1365` | 严格 3:4 竖版 |
| `quality` | `high` | 保证刀模线与手写文字清晰 |
| `background` | `opaque` | 纯白背景 |

> 耗时主要在**图生图推理**（约 30–90 秒），与平台无关，属正常现象。

`SKILL.md` 内已内置可填空的 Prompt 模板，无需每次重写长提示词。

## 使用

安装后，直接向 Agent 描述需求即可触发，例如：

- "帮我把这张照片做成人物冰箱贴，姓名叫小明"
- "用这张照片生成一个旅行打卡冰箱贴海报"
- "把这个人做成冰箱贴风格的图标，写上名字"

## 避免事项

- 不做成普通拼贴
- 不画得复杂
- 不添加多余装饰元素
- 不出现乱码文字
- 不过度卡通化
- 不让冰箱贴图标太大
- 不让文字和人物脱离，必须融成一个整体
